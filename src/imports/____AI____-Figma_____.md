# 短剧剧本 AI 创作工具 — Figma AI 设计提示词

> 以下提示词可直接复制粘贴到 Figma AI 设计工具（如 Magician、Figma AI、Builder.io 等）中执行。建议按「全局规范 → 逐页设计」分段投喂，每段生成后再进入下一段。

---

## 一、全局设计规范（先执行此段）

```
请为一款名为「ScriptForge」的短剧剧本 AI 创作工具设计 Web 端高保真 UI。

【产品定位】
面向短剧创作者的 AI 辅助剧本生成平台，用户通过 7 步向导式工作流，从故事设定到分镜脚本全自动生成，支持 AI 重生成、原地编辑和多格式导出。

【设计风格】
- 整体风格：现代简约、专业创作工具感，类似 Notion / Linear / Cursor 的暗色+亮色双主题，默认深色主题
- 主色调：深靛蓝 #1A1A2E 背景，搭配科技感渐变强调色（紫色 #6C5CE7 到蓝色 #0984E3）
- 辅助色：成功绿 #00B894、警告橙 #FDCB6E、危险红 #E17055
- 字体：Inter / SF Pro，标题 600，正文 400，等宽代码用 JetBrains Mono
- 圆角：卡片 12px，按钮 8px，输入框 8px
- 阴影：柔和投影，卡片 elevation 1-2 级
- 间距：8px 栅格体系

【布局结构】
- 顶部导航栏（固定）：左侧 Logo + 项目名，中间步骤进度条，右侧用户头像 + 设置
- 左侧边栏（可折叠）：当前步骤的章节导航 / 内容目录
- 主内容区：居中最大宽度 1200px
- 右侧面板（可折叠）：AI 修改意见输入框 + 提示词编辑器 + 操作历史

【通用组件规范】
1. 主按钮：渐变背景（紫→蓝），白色文字，hover 时亮度+10%
2. 次按钮：透明背景 + 边框，hover 时背景变灰
3. 输入框：深色填充 #2D2D44，边框 #3D3D5C，focus 时边框变主色
4. 卡片：背景 #252540，边框 #3D3D5C，内边距 24px
5. 标签 Tag：小圆角，不同题材用不同颜色区分
6. 步骤进度条：横向 Stepper，已完成步骤打勾，当前步骤高亮，未到达步骤灰色
7. AI 生成内容区块：左侧有渐变竖条标识，右上角有「重新生成」「编辑」「恢复AI结果」三个图标按钮
8. 修改意见框：贴在 AI 内容区块右侧或下方，textarea + 提交按钮
9. 提示词弹窗：Modal 形式，代码编辑器风格，有「恢复默认」「保存」按钮
10. Loading 状态：骨架屏 + 渐变闪烁动画，AI 生成时显示

【设计尺寸】
- 画布宽度：1440px（桌面端）
- 顶部导航高度：64px
- 侧边栏宽度：240px（展开）/ 56px（折叠）
- 右侧面板宽度：320px（展开）

请先输出设计系统页（Design System），包含：颜色色板、字体规范、按钮样式（3态）、输入框样式（3态）、卡片样式、Tag 样式、图标库、步骤条组件。
```

## 二、首页设计

```
请设计「ScriptForge」的首页（Landing + Dashboard 混合风格）。

【页面结构】
1. 顶部导航栏：Logo「ScriptForge」+ 导航（首页/项目/模板/帮助）+ 右侧用户头像
2. Hero 区域（上半屏）：
   - 左侧大标题：「用 AI 从零生成你的短剧剧本」
   - 副标题：「7 步工作流，从故事设定到分镜脚本，一站式完成」
   - 主按钮：「+ 新建项目」（大尺寸，渐变）
   - 次按钮：「查看教程」
   - 右侧：产品截图占位 / 抽象渐变插画
3. 历史项目区域（下半屏）：
   - 标题：「我的项目」+ 右侧「全部项目」链接
   - 项目卡片网格（3列），每张卡片包含：
     - 封面缩略图（渐变占位，带题材标签）
     - 项目名称（如「霸总爱上小秘书」）
     - 元信息：市场地区 Tag | 集数 | 题材 Tag | 当前进度步骤
     - 最后编辑时间
     - 悬停时显示「继续编辑」「删除」操作
   - 空状态：居中插画 + 「还没有项目，点击上方按钮创建第一个项目」

【交互细节】
- 新建项目按钮点击后弹出项目创建向导（即第一步页面）
- 项目卡片支持悬停浮起效果
- 页面有微妙的背景渐变光斑装饰

请输出 1440px 宽的首页完整设计。
```

## 三、第一步：项目基础设定页

```
请设计短剧剧本创作工具的「第一步：项目基础设定」页面。

【页面布局】
- 顶部：步骤进度条显示 7 步，第 1 步高亮
- 主内容区：居中表单卡片，最大宽度 800px
- 页面标题：「第一步：项目基础设定」+ 副标题「填写基本信息，AI 将据此生成人物和故事」

【表单字段（从上到下排列）】

1. 市场地区（必选，单选 Radio Card 形式）
   - 三个选项卡片横向排列：欧美 | 拉美 | 国内
   - 每张卡片有图标 + 名称 + 简短描述
   - 选中状态：边框变主色 + 左上角勾选角标

2. 故事题材（必选，多选 Chip/Tag 形式）
   - 标题下方有提示：「根据市场地区动态显示可选题材」
   - 题材以可点击的 Tag 云形式展示，选中后填充主色
   - 欧美/拉美术材：狼人/吸血鬼、霸总、大女主、隐藏身份、先婚后爱、复仇、逆袭、穿越、重生、身份互换、追妻火葬场、萌宝、LGBT
   - 国内题材：赘婿、战神/龙王、修仙玄幻、逆袭、历史古代、权谋、系统流、大女主、霸总、甜宠、萌宝、重生、穿越、真假千金、闪婚契约、复仇、虐恋情深、女帝/王妃、替身/白月光
   - 已选题材在上方以 Tag 形式汇总显示

3. 全剧集数（必选，单选下拉或分段控件）
   - 选项：20 / 30 / 40 / 50 / 60 / 70 / 80 / 90 / 100
   - 用 Segmented Control 或下拉选择

4. 全剧时长（必填，数字输入框）
   - 输入框 + 单位「分钟」
   - 下方有辅助文字：「建议单集 1-2 分钟」

5. 剧本语言（必选，单选）
   - 选项：中文（默认）| 英文
   - 说明文字：「除人物名、家族名、台词、画面字之外的内容使用的语言」

6. 台词语言（必选，单选）
   - 选项：中文（默认）| 英（主）中（辅）| 英文
   - 说明文字：「英（主）中（辅）= 英文为主，括号标注中文翻译」

7. 故事梗概（与人物小传至少选一个，Textarea）
   - 大文本输入框，placeholder：「输入你的故事梗概，越详细越好…」
   - 右下角字数统计
   - 左上角标注「可选」

8. 人物小传（与故事梗概至少选一个，动态列表）
   - 标题 + 「+ 添加人物」按钮
   - 每个人物为一个子卡片，包含：
     - 姓名（输入框）
     - 性别（单选：男/女/其他）
     - 是否主角（Switch 开关）
     - 人物介绍（Textarea）
     - 右上角删除按钮
   - 默认显示 1 个空的人物卡片

【底部操作栏】
- 左侧：「提示词」按钮（点击弹出提示词编辑器 Modal）
- 右侧：「确认提交，下一步 →」主按钮
- 按钮上方有校验提示：「故事梗概和人物小传请至少填写一项」

【提示词弹窗内容】
- 标题：「编辑提示词模板」
- 代码编辑器风格的文本域，预填默认提示词（含变量占位符如「{市场地区}」「{故事题材}」等，变量用高亮色标注）
- 底部：「恢复默认」次按钮 + 「保存」主按钮

请输出完整页面设计，包含表单各状态（默认/填写/选中/错误）。
```

## 四、第二步：人物设定 / 背景设定 / 故事线页

```
请设计短剧剧本创作工具的「第二步：人物设定、背景设定与故事线」页面。

【页面布局】
- 顶部：步骤进度条，第 2 步高亮，第 1 步已完成可点击返回
- 左侧边栏：三个锚点导航（人物设定 / 背景设定 / 故事线），点击滚动定位
- 主内容区：三个 AI 生成内容区块纵向排列
- 右侧面板：修改意见输入区

【区块一：人物设定】
- 区块标题：「人物设定」+ 右侧「重新生成」按钮
- 每个人物为一张人物卡片：
  - 左侧：头像占位（圆形，渐变背景 + 姓名首字母）
  - 右侧：
    - 姓名行：姓名文本 + 「编辑」铅笔图标 + 「AI推荐」魔法棒按钮
    - 性别 / 身份标签
    - 人物详细描述（多行文本）
  - 卡片右上角：「编辑」「恢复AI结果」图标按钮
- 姓名编辑交互：
  - 点击编辑 → 姓名变为输入框，可直接修改
  - 点击「AI推荐」→ 弹出下拉面板，显示 5 个推荐名字 + 每个不超过 100 字的推荐理由，点击选中后一键替换
- 人物卡片支持展开/折叠

【区块二：背景设定】
- 区块标题：「背景设定」+ 右侧「重新生成」按钮
- 富文本展示区域，AI 生成的世界观/时代/地点等设定
- 右上角：「编辑」「恢复AI结果」图标按钮
- 点击编辑 → 变为可编辑的富文本区域

【区块三：故事线】
- 区块标题：「故事线」+ 右侧「重新生成」按钮
- 以时间线 / 多条故事线并列的形式展示
- 每条故事线有标签（如「主线」「副线A」「感情线」）+ 内容描述
- 右上角：「编辑」「恢复AI结果」图标按钮

【右侧修改意见面板（固定）】
- 标题：「AI 修改意见」
- 下拉选择：修改对象（人物设定 / 背景设定 / 故事线）
- Textarea：「输入修改方向，如：让女主更强势一些…」
- 「提交修改」按钮
- 下方提示：「AI 将根据你的意见重新生成该部分内容」

【三种修改方式的视觉表达】
1. 返回上一步：顶部步骤条第 1 步可点击
2. 修改意见重生成：右侧面板
3. 原地编辑：每个区块的「编辑」按钮，编辑后出现「保存」「取消」按钮，以及「恢复AI结果」按钮

【底部操作栏】
- 左侧：「← 返回上一步」次按钮 + 「提示词」按钮
- 右侧：「确认提交，下一步 →」主按钮

请输出完整页面，包含 AI 生成中（骨架屏）、生成完成、编辑中三种状态。
```

## 五、第三步：分段粗纲页

```
请设计短剧剧本创作工具的「第三步：分段粗纲」页面。

【页面布局】
- 顶部：步骤进度条，第 3 步高亮
- 左侧边栏：段落导航列表（如「第1段（1-20集）」「第2段（21-40集）」…），当前查看段落高亮
- 主内容区：当前选中段落的详细内容
- 右侧面板：修改意见输入区

【核心概念说明】
- 根据总集数不同，分段规则不同：
  - 20/30/40集：跳过此步
  - 50集：每10集一段
  - 60集：每15集一段
  - 70集：每14集一段
  - 80/100集：每20集一段
  - 90集：每15集一段
- 每段包含：剧情简介（约1000字）、开场钩子、结尾钩子

【主内容区 - 段落详情卡片】
- 卡片头部：
  - 段落标题：「第 1 段 · 第 1-20 集」
  - 状态标签：已生成 / 生成中 / 待生成
  - 操作按钮：「重新生成」「编辑」「恢复AI结果」
- 卡片内容：
  - 「开场钩子」子区块：引用样式，左侧竖线 + 文字
  - 「剧情简介」子区块：正文文本，约 1000 字
  - 「结尾钩子」子区块：引用样式
- 卡片底部：
  - 「上一段」「下一段」切换按钮
  - 进度指示：「3 / 4 段已生成」

【左侧段落导航】
- 每个段落项显示：段落编号 + 集数范围 + 状态圆点（绿=已生成，蓝=生成中，灰=待生成）
- 生成中的段落显示进度条

【右侧修改意见面板】
- 标题：「修改意见」
- 自动识别当前段落：「第 X 段」
- Textarea 输入修改方向
- 「提交修改」按钮
- 提示：仅重新生成当前段落

【批量生成进度】
- 顶部有一个生成进度条：「AI 正在分段生成粗纲… 第 2/4 段」
- 支持「暂停生成」按钮

【底部操作栏】
- 左侧：「← 返回上一步」+「提示词」
- 右侧：「全部生成完成后，下一步 →」主按钮（未全部完成时置灰）

请输出完整页面，包含多段落切换、生成中进度、单段编辑状态。
```

## 八、第六步：分镜脚本页

```
请设计短剧剧本创作工具的「第六步：分镜脚本」页面。这是核心产出页面。

【页面布局】
- 顶部：步骤进度条，第 6 步高亮
- 顶部下方：全剧集数 Tab 栏（横向可滚动 Tab：第1集 | 第2集 | …），当前集高亮，已生成集有绿点
- 左侧边栏：当前集的分镜场景列表（如 1-1 / 1-2 / 1-3 …）
- 主内容区：分镜脚本正文，剧本格式
- 右侧面板：修改意见 + 导出操作

【分镜脚本正文格式（关键）】
每集分镜脚本按以下格式展示，用等宽字体或剧本专用排版：

```
第 1 集

1-1  王侯府演武场 / 外 / 日
人物：赵辰（年轻版）、赵天、周围子弟 N 人

## 使用建议

1. **分段投喂**：将上述 11 段分别复制到 Figma AI 中，每段生成一个 Frame/Page
2. **先做设计系统**：第一段生成的 Design System 是后续所有页面的基础，务必先生成并锁定
3. **统一命名**：所有页面 Frame 命名建议：`01_首页` / `02_第一步_项目设定` / `03_第二步_人物故事` …
4. **组件化**：生成后将按钮、输入框、卡片、AI 内容块等转为 Component，便于后续统一修改
5. **变量绑定**：颜色、字体、圆角建议绑定 Variables，方便切换亮/暗主题
